TensorFold changes to the vendored files ("modified" rows below):
- every quoted #include is rewritten to a path relative to the including file (TensorFold's SM70 JIT admits no
  extra include roots); applies to all files that include another vendored file;
- ds41kern_op.cu: the TORCH_LIBRARY(ds41kern) registration and <torch/library.h> are replaced by the
  ds41kern::lattice_gemm_op / variant_name_op entry points for the pybind module.
- exact weight decode (ds41-lattice2): gguf_prefill_transcode.cuh adds the exact-sub-scale stats encoding
  (GroupExact, transcode_kernel<Type, Exact>), the TurboMind lattice transform an Exact decode, ds41kern_variants.cuh
  the exact instantiations (FP32-output gate|up, FP16 down) of the rule's tilings;
- the friend's FP16 lattice arithmetic is removed (R2, 2.6x the operator error): ds41kern_variants.cuh builds only
  the five exact variants (kVariants 5), ds41kern_op.cu selects FP32 output for variants 0/1, and
  gguf_prefill_transcode_sm70.cu launches only the exact encoding of IQ2_XXS / IQ2_XS / IQ1_M (no `exact` argument).
- GGUF expert staging uses the strides of the owned contiguous device banks. TensorFold no longer materializes
  per-expert address tables for the transcode launch. The packet and statistic encodings are unchanged.
- IQ1_M exact GEMM staging copies the unchanged codebook in 16-byte vectors. The source and dynamic shared
  base are aligned to 16 bytes (`lattice_codebooks.h`, `gemm_universal.h`). The first operand barrier publishes
  the staged table (`lattice_transform.h`, `mainloop_sm70.h`).
